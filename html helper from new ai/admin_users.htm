3.1. Управление пользователями

Содержание ›› Администрирование ››

Раздел «Пользователи» (меню «Данные → Пользователи») предназначен для управления учётными записями сотрудников, имеющих доступ к системе. Этот раздел доступен только пользователям с ролью «Администратор».

Таблица «Пользователи» содержит следующие колонки:

Колонка Описание
FIO ФИО пользователя (сотрудника)
role Роль пользователя (Admin или Employer)
login Уникальное имя пользователя для входа в систему
password Хэш пароля (не читается, отображается в зашифрованном виде)

Рис. 3. Специальная запись системного администратора (user_id = -1)


Особенности раздела

— Доступность: раздел виден и доступен только пользователям с ролью «Admin».

— Системный администратор: в базе данных по умолчанию присутствует запись с user_id = -1 (логин «Admin»). Эта запись защищена от удаления через интерфейс.

— Пароль: хранится в базе данных в виде хэша SHA-512, поэтому в таблице отображается нечитаемая строка.

— Поиск и фильтрация: для таблицы пользователей доступны стандартные механизмы поиска и фильтрации (по ФИО, логину, роли).

Основные операции с пользователями

Для управления учётными записями используются стандартные кнопки:

— Добавить — создание новой учётной записи (раздел 3.1.2).

— Редактировать — изменение данных существующего пользователя (раздел 3.1.3).

— Удалить — удаление учётной записи (кроме системного администратора с user_id = -1).
