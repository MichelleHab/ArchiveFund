Управление группами (Group)

Назначение

Модуль «Группы» предназначен для учёта учебных групп. Каждая группа характеризуется названием, годом создания и специализацией.

Поля формы

Имя группы

Текстовое поле для ввода названия учебной группы. Примеры: ИВТ-41, ПИ-22, ЭО-11. Обязательное поле.

Год создания

Поле выбора даты. Укажите год формирования группы.

Специализация

Выпадающий список с автозаполнением. Выберите или введите специализацию группы. Система предлагает варианты из существующих записей. Обязательное поле.

Добавление новой группы

  1. В главном окне выберите меню Таблицы → Группы
  2. Нажмите кнопку «Добавить»
  3. Заполните поля формы:
    • Введите имя группы (обязательно)
    • Укажите год создания
    • Выберите или введите специализацию (обязательно)
  4. Нажмите кнопку «Сохранить»

Редактирование группы

  1. В таблице выберите нужную строку с группой
  2. Нажмите кнопку «Изменить»
  3. Внесите необходимые изменения в поля формы
  4. Нажмите кнопку «Сохранить»

Удаление группы

  1. В таблице выберите строку с группой
  2. Нажмите кнопку «Удалить»
  3. Подтвердите удаление в диалоговом окне
Внимание! Если в группе есть студенты или коробки с документами, система может запретить удаление.

Связанные данные

Таблица Связь
Студенты Одна группа может включать多个 студентов
Коробки Одна группа может иметь несколько коробок с документами

Примеры специализаций

Специализация определяет профиль подготовки студентов в группе. Примеры:

  • Информационные системы и технологии
  • Программная инженерия
  • Экономика предприятий
  • Менеджмент организации
  • Прикладная математика

Поиск групп

Для быстрого поиска группы используйте поле поиска в главном окне. Можно искать по:

  • Имени группы
  • Году создания
  • Специализации

Просмотр документов группы

Система позволяет просмотреть все документы, относящиеся к конкретной группе:

  1. Выберите группу в таблице
  2. Используйте функцию просмотра связанных документов
  3. Система отобразит документы из коробок, привязанных к этой группе
