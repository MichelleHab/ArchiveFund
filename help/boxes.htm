Управление коробками (Boxes)

Назначение

Модуль «Коробки» предназначен для учёта физических контейнеров (коробок), в которых хранятся документы архива. Каждая коробка привязана к определённому стеллажу и полке.

Поля формы

Имя коробки

Текстовое поле для ввода наименования коробки. Примеры: А1, АБ17, Н1.

Автоматическая генерация: При вводе номера стеллажа и номера полки имя коробки генерируется автоматически в формате Box:{стеллаж}-{полка}.

Номер стеллажа

Числовое поле. Указывает номер стеллажа в помещении архива.

Номер полки

Числовое поле. Указывает номер полки на выбранном стеллаже.

Группа

Выпадающий список. Выберите учебную группу, документы которой хранятся в этой коробке. Список заполняется из таблицы «Группы».

Тип хранимых документов

Выпадающий список. Выберите тип документов для этой коробки. Список заполняется из справочника «Типы документов».

Год работы

Поле выбора даты. Укажите год формирования коробки. Можно установить флажок «Не сохранять дату», чтобы оставить поле пустым.

Добавление новой коробки

  1. В главном окне выберите меню Таблицы → Коробки
  2. Нажмите кнопку «Добавить»
  3. Заполните поля формы:
    • Введите номер стеллажа и полки (имя сгенерируется автоматически)
    • Выберите группу из списка
    • Выберите тип документов
    • При необходимости укажите год работы
  4. Нажмите кнопку «Сохранить»
Примечание: Тип документов должен быть предварительно создан в справочнике «Типы документов».

Редактирование коробки

  1. В таблице выберите нужную строку с коробкой
  2. Нажмите кнопку «Изменить»
  3. Внесите необходимые изменения в поля формы
  4. Нажмите кнопку «Сохранить»

Удаление коробки

  1. В таблице выберите строку с коробкой
  2. Нажмите кнопку «Удалить»
  3. Подтвердите удаление в диалоговом окне
Внимание! Если в коробке хранятся документы, система может запретить удаление или потребовать подтверждения.

Связанные данные

Таблица Связь
Группы Одна группа может иметь несколько коробок
Типы документов Один тип может использоваться в нескольких коробках
Документы Каждый документ привязан к одной коробке
