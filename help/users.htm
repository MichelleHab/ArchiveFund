Управление пользователями (User)

Назначение

Модуль «Пользователи» предназначен для управления учётными записями пользователей системы. Доступ к модулю имеют только пользователи с ролью Admin.

Примечание: Меню «Пользователи» видно только администраторам. Пользователи с ролью Manager не имеют доступа к этому разделу.

Поля формы пользователя

ФИО

Текстовое поле для ввода полного имени пользователя (фамилия, имя, отчество).

Роль

Выпадающий список. Выберите роль пользователя:

  • Admin — полный доступ ко всем функциям системы
  • Manager — доступ к основным функциям без права управления пользователями

Логин

Текстовое поле для ввода имени пользователя. Используется для входа в систему. Обязательное поле.

Пароль

Текстовое поле для ввода пароля. Обязательное поле при создании нового пользователя. При редактировании существующего пользователя поле можно оставить пустым, чтобы не менять пароль.

Безопасность: Пароли хранятся в базе данных в хешированном виде с использованием алгоритма SHA-512.

Добавление нового пользователя

  1. В главном окне выберите меню Пользователи
  2. Нажмите кнопку «Добавить»
  3. Заполните поля формы:
    • Введите ФИО пользователя
    • Выберите роль из списка (обязательно)
    • Введите логин (обязательно)
    • Введите пароль (обязательно)
  4. Нажмите кнопку «Сохранить»

Редактирование пользователя

  1. В таблице выберите нужную строку с пользователем
  2. Нажмите кнопку «Изменить»
  3. Внесите необходимые изменения:
    • При изменении пароля введите новый пароль
    • Для сохранения текущего пароля оставьте поле пустым
  4. Нажмите кнопку «Сохранить»

Удаление пользователя

  1. В таблице выберите строку с пользователем
  2. Нажмите кнопку «Удалить»
  3. Подтвердите удаление в диалоговом окне
Внимание! Не рекомендуется удалять последнего пользователя с ролью Admin. Это может привести к потере возможности управления системой.

Резервное копирование базы данных

В окне управления пользователями доступна функция создания резервных копий базы данных.

Создание резервной копии

  1. В окне пользователей нажмите кнопку «Резервная копия»
  2. В диалоговом окне выберите место сохранения файла
  3. Подтвердите создание копии

Файл резервной копии сохраняется в формате SQL с именем вида backup_ГГГГММДД_ЧЧММСС.sql.

Восстановление из резервной копии

  1. В окне пользователей нажмите кнопку «Восстановить»
  2. Выберите файл резервной копии
  3. Подтвердите восстановление
Внимание! При восстановлении все текущие данные будут перезаписаны данными из резервной копии. Эта операция необратима!

Роли пользователей

Роль Права доступа
Admin
  • Полный доступ ко всем таблицам
  • Управление пользователями
  • Создание и восстановление резервных копий
  • Доступ ко всем функциям системы
Manager
  • Доступ к таблицам: Коробки, Документы, Студенты, Группы
  • Просмотр и редактирование данных
  • Нет доступа к управлению пользователями
  • Нет доступа к резервному копированию

Таблица пользователей

Данные о пользователях хранятся в таблице User со следующими полями:

Поле Описание
user_id Уникальный идентификатор пользователя
FIO ФИО пользователя
role Роль пользователя (Admin/Manager)
login Имя для входа в систему
password Хешированный пароль (SHA-512)

Рекомендации по безопасности

  • Используйте сложные пароли (не менее 8 символов, буквы и цифры)
  • Регулярно создавайте резервные копии базы данных
  • Не используйте одну учётную запись несколькими пользователями
  • При увольнении сотрудника немедленно удалите или заблокируйте его учётную запись
  • Храните резервные копии в защищённом месте
