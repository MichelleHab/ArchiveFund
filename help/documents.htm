Управление документами (Documents)

Назначение

Модуль «Документы» предназначен для учёта студенческих работ, хранящихся в архиве. Система поддерживает различные типы документов: дипломные работы, курсовые проекты, рефераты, статьи и другие.

Поля формы

Тема документа

Текстовое поле для ввода названия или темы документа. Обязательное поле.

Дата создания

Поле выбора даты. Укажите дату создания документа.

Тип документа

Выпадающий список. Выберите тип документа из справочника (дипломная работа, курсовая, реферат и т.д.). Обязательное поле.

Руководитель

Текстовое поле с автозаполнением. Введите ФИО научного руководителя. Система предлагает варианты из существующих записей.

Студент

Выпадающий список. Выберите студента — автора документа. Список заполняется из таблицы «Студенты». Обязательное поле.

Коробка с файлом

Выпадающий список. Выберите коробку, в которой физически хранится документ. Отображается в формате id:{ID}-> {имя коробки}.

Добавление нового документа

  1. В главном окне выберите меню Таблицы → Документы
  2. Нажмите кнопку «Добавить»
  3. Заполните поля формы:
    • Введите тему документа (обязательно)
    • Укажите дату создания
    • Выберите тип документа (обязательно)
    • Введите ФИО руководителя
    • Выберите студента из списка (обязательно)
    • Выберите коробку для хранения
  4. Нажмите кнопку «Сохранить»
Примечание: Перед добавлением документа должны быть созданы: студент, тип документа и коробка.

Редактирование документа

  1. В таблице выберите нужную строку с документом
  2. Нажмите кнопку «Изменить»
  3. Внесите необходимые изменения
  4. Нажмите кнопку «Сохранить»

Удаление документа

При удалении документ не удаляется безвозвратно, а перемещается в таблицу DeletedDocuments (Удалённые документы). Это позволяет сохранить историю и восстановить запись при необходимости.

  1. В таблице выберите строку с документом
  2. Нажмите кнопку «Удалить»
  3. Подтвердите удаление
Информация: Удалённые документы можно просмотреть, выбрав в меню Таблицы → Удалённые документы.

Просмотр удалённых документов

Таблица DeletedDocuments содержит те же поля, что и основная таблица документов:

  • Тема
  • Дата создания
  • Тип
  • Руководитель
  • Студент
  • Коробка с файлом

Связанные данные

Таблица Связь
Студенты Один студент может иметь несколько документов
Типы документов Один тип может использоваться во многих документах
Коробки В одной коробке может храниться несколько документов

Типы документов

В системе поддерживаются следующие типы документов (список может быть расширен):

  • Дипломная работа
  • Курсовая работа
  • Реферат
  • Статья
  • Патент
  • Сертификат
  • Свидетельство

Поиск документов

Для быстрого поиска документа используйте поле поиска в главном окне. Можно искать по:

  • Теме документа
  • ФИО студента
  • ФИО руководителя
  • Названию типа документа
  • Имени коробки
