О программе

ArchiveFund — это система управления архивом студенческих документов. Приложение позволяет:

  • Вести учёт коробок с документами на стеллажах
  • Хранить информацию о документах (дипломные работы, курсовые, рефераты, статьи)
  • Управлять данными о студентах и их персональных делах
  • Контролировать принадлежность документов к учебным группам
  • Разграничивать доступ пользователей по ролям
  • Создавать резервные копии базы данных

Система работает с СУБД MySQL и использует Windows Forms для пользовательского интерфейса.

Установка и настройка

Требования

  • Операционная система Windows
  • СУБД MySQL версии 8.0 или выше
  • .NET Framework / .NET 6+

Файл конфигурации

Для настройки подключения к базе данных используется файл config.ini, который должен находиться в папке с программой. Пример содержимого:

Параметр Описание
server Адрес сервера MySQL (например, localhost или IP-адрес)
port Порт подключения (по умолчанию 3306)
database Имя базы данных (по умолчанию ArchiveFund)
user Имя пользователя MySQL
password Пароль пользователя
Примечание: Если файл конфигурации отсутствует, программа автоматически создаст базу данных ArchiveFund с пустой структурой.

Первый запуск

При первом запуске программа:

  1. Проверяет наличие файла config.ini
  2. Проверяет существование указанной базы данных
  3. При необходимости создаёт структуру таблиц
  4. Создаёт пользователя MySQL с указанными правами доступа

Авторизация

При запуске приложения открывается окно авторизации.

Поля ввода

  • Логин — имя пользователя в системе
  • Пароль — пароль для входа
Внимание! Пароли хранятся в базе данных в хешированном виде (алгоритм SHA-512).

Сообщения об ошибках

  • «Не введен логин!» — поле логина пустое
  • «Не введен пароль!» — поле пароля пустое
  • «Данный логин не найден!» — пользователь с таким логином не существует
  • «Неверный логин или пароль!» — пароль не совпадает с сохранённым

Главное окно

После успешной авторизации открывается главное окно программы. В заголовке окна отображаются:

  • Название программы
  • Логин текущего пользователя
  • ФИО пользователя

Меню программы

  • Файл — основные операции с данными
  • Таблицы — выбор таблицы для просмотра и редактирования
  • Пользователи — управление учётными записями (доступно только администраторам)
  • Справка — вызов данной справочной системы

Панель поиска

В верхней части окна расположено поле поиска для фильтрации записей по тексту.

Таблица данных

Основная область окна занимает таблица с данными выбранной сущности. Под таблицей отображается статус с количеством полученных строк.

Работа с таблицами

Система предоставляет доступ к следующим таблицам:

Коробки (Boxes)

Таблица хранит информацию о физических коробках для хранения документов.

Поля таблицы

Поле Описание
Имя Наименование коробки (например, А10, АБ17, Н1)
Номер стеллажа Номер стеллажа в архиве
Номер полки Номер полки на стеллаже
Группа Учебная группа, к которой относятся документы в коробке
Тип хранимых документов Тип документов, хранящихся в коробке
Год работы Год создания/формирования коробки

Добавление/редактирование

При создании новой коробки можно указать:

  • Имя коробки (генерируется автоматически при вводе номера стеллажа и полки)
  • Номер стеллажа и полки
  • Группу из выпадающего списка
  • Тип документов из выпадающего списка
  • Год работы (опционально)

Документы (Documents)

Таблица содержит сведения о документах, хранящихся в архиве.

Поля таблицы

Поле Описание
Тема Название или тема документа
Дата создания Дата создания документа
Тип Тип документа (дипломная, курсовая и т.д.)
Руководитель ФИО научного руководителя
Студент ФИО студента — автора документа
Коробка с файлом Коробка, в которой хранится документ

Удалённые документы

Удалённые документы перемещаются в таблицу DeletedDocuments, где сохраняется вся информация о них.

Студенты (Student)

Таблица содержит информацию о студентах.

Поля таблицы

Поле Описание
ФИО Полное имя студента
Группа Учебная группа студента

Персональные дела

Дополнительно хранятся персональные дела студентов (StudentsPersFiles):

  • Год отчисления
  • Причина отчисления
  • Год поступления

Группы (Group)

Таблица учебных групп.

Поля таблицы

Поле Описание
Имя группы Название учебной группы
Год создания Год формирования группы
Специализация Профиль подготовки группы

Типы документов (DocumentTypes)

Справочник типов документов (дипломные работы, курсовые, рефераты, статьи и др.).

Пользователи (User)

Таблица учётных записей пользователей системы.

Поля таблицы

Поле Описание
ФИО Полное имя пользователя
Роль Роль пользователя (Admin, Manager)
Логин Имя для входа в систему
Пароль Хешированный пароль

Фильтрация данных

Система предоставляет гибкие возможности фильтрации отображаемых данных.

Поиск по тексту

Введите текст в поле поиска — система отобразит только строки, содержащие этот текст в любом из полей.

Контекстный фильтр

Через меню Таблицы → Фильтр можно установить фильтрацию по значениям конкретных столбцов:

  1. Выберите пункт «Фильтр» в меню
  2. Выберите интересующий столбец
  3. Выберите конкретное значение или опцию «Все»
Подсказка: Активные фильтры подсвечиваются зелёным цветом. Для сброса всех фильтров выберите пункт «Сбросить все фильтры».

Резервное копирование

Администраторы могут создавать резервные копии базы данных и восстанавливать их.

Создание резервной копии

  1. Откройте окно управления пользователями
  2. Нажмите кнопку «Резервная копия»
  3. Выберите место сохранения файла
  4. Подтвердите создание копии

Файл резервной копии сохраняется в формате SQL с именем вида backup_ГГГГММДД_ЧЧММСС.sql.

Восстановление из резервной копии

  1. Откройте окно управления пользователями
  2. Нажмите кнопку «Восстановить»
  3. Выберите файл резервной копии
  4. Подтвердите восстановление
Внимание! При восстановлении все текущие данные будут перезаписаны данными из резервной копии.

Роли пользователей

Система поддерживает две роли пользователей:

Роль Права доступа
Admin Полный доступ ко всем функциям, включая управление пользователями и резервное копирование
Manager Доступ к основным функциям работы с данными без права управления пользователями

Меню «Пользователи» видно только пользователям с ролью Admin.
