Управление студентами (Student)

Назначение

Модуль «Студенты» предназначен для учёта студентов и их персональных дел. Система хранит основную информацию о студенте и данные о его обучении.

Поля формы студента

ФИО студента

Текстовое поле для ввода полного имени студента (фамилия, имя, отчество). Обязательное поле.

Группа

Выпадающий список. Выберите учебную группу, к которой относится студент. Список заполняется из таблицы «Группы».

Персональные дела студентов

Дополнительно к основной информации система хранит персональные дела (StudentsPersFiles) со следующими данными:

Год поступления

Поле выбора даты. Укажите год поступления студента в учебное заведение.

Год отчисления

Поле выбора даты. Укажите год отчисления студента. Можно установить флажок «Не сохранять дату», если студент ещё не отчислен.

Причина отчисления

Текстовое поле для указания причины отчисления. Примеры:

  • Отчисление
  • Перевод в другое учреждение
  • Академический отпуск
  • Окончание обучения

Добавление нового студента

  1. В главном окне выберите меню Таблицы → Студенты
  2. Нажмите кнопку «Добавить»
  3. Заполните поля формы:
    • Введите ФИО студента (обязательно)
    • Выберите группу из списка
    • Укажите год поступления
    • При необходимости укажите год и причину отчисления
  4. Нажмите кнопку «Сохранить»
Примечание: Учебная группа должна быть предварительно создана в справочнике «Группы».

Редактирование данных студента

  1. В таблице выберите нужную строку со студентом
  2. Нажмите кнопку «Изменить»
  3. Внесите необходимые изменения в поля формы
  4. Нажмите кнопку «Сохранить»

Удаление студента

При удалении студента его персональное дело перемещается в таблицу DeletedStudentsPersFiles (Удалённые персональные дела).

  1. В таблице выберите строку со студентом
  2. Нажмите кнопку «Удалить»
  3. Подтвердите удаление в диалоговом окне
Внимание! Если у студента есть документы в архиве, удаление может потребовать дополнительного подтверждения.

Просмотр всех документов студента

Система позволяет просмотреть все документы, связанные с конкретным студентом:

  1. Выберите студента в таблице
  2. Используйте функцию экспорта или просмотра связанных документов
  3. Система отобразит:
    • Все текущие документы студента из таблицы Documents
    • Все удалённые документы из таблицы DeletedDocuments

Поиск студентов

Для быстрого поиска студента используйте поле поиска в главном окне. Можно искать по:

  • ФИО студента (полностью или частично)
  • Названию группы
