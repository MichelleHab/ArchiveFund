Часть 1. Форма документа (DocumentForm)

Форма DocumentForm предназначена для ввода мета-данных архивного документа: темы, авторов, типа и местоположения. Поля, отмеченные звездочкой (*), являются обязательными для заполнения.

Рис. 1. Общий вид формы редактирования документа

1. Основная информация

* Тема документа Многострочное текстовое поле.
Введите краткое описание или заголовок работы.
Удаленный документ? Чекбокс.
Устанавливается, если документ помечен как удаленный (архивная пометка).

2. Классификация и авторы

  • * Год создания: Выберите год в календаре.
  • * Тип документа: Выберите из выпадающего списка.
  • ФИО руководителя: Выберите или введите необходимого руководителя.
  • * Студент: Выберите студента-автора работы.
  • Коробка хранения: Указывает физическое расположение (формат: id:ID -> Имя).
Важно: При нажатии кнопки Принять система проверит заполнение обязательных полей (Тема, Тип, Студент). Если что-то пропущено, сохранение не произойдет.

Часть 2. Форма типа документа (DocumentTypeForm)

Данная форма является вспомогательной и используется для создания или редактирования справочника типов документов. Она позволяет задать название для нового вида архивных записей (например, «Курсовая работа», «Диплом», «Лекция»).

Рис. 2. Окно добавления/изменения типа документа

Элементы управления

Интерфейс формы максимально упрощен и содержит всего один основной элемент ввода:

Элемент Описание
* Название типа Текстовое поле.
Предназначено для ввода наименования типа документа.
Пример: «Зачет», «Экзаменационная ведомость», «Реферат».
Принять Кнопка. Сохраняет введенное название в базу данных.
Если поле пустое, появится сообщение об ошибке: «Не введено название типа документа!».
Отмена Кнопка. Закрывает окно без сохранения изменений.

Режимы работы

  • Добавление: Если форма открыта для создания новой записи, заголовок окна будет гласить «Добавление типа документа!». Поле ввода будет пустым.
  • Изменение: Если вы редактируете существующий тип, заголовок изменится на «Изменение типа документа!», а в поле ввода отобразится текущее название типа, которое можно отредактировать.
