Руководство пользователя АРМ "Архивный фонд"

Данная справка описывает работу с основным окном программы, навигацию по базам данных, поиск, редактирование записей и функции печати.

1. Обзор главного окна

После входа в систему вы попадаете на главную форму. Интерфейс разделен на несколько ключевых зон.

Рис. 1. Общий вид интерфейса программы

  • Главное меню (вверху): Содержит разделы «Файл», «Данные», «Студенты», «Справочник» и «Печати». Через него осуществляется выбор таблицы для просмотра.
  • Панель инструментов (под меню): Быстрый доступ к кнопкам «Добавить», «Редактировать», «Удалить».
  • Поле поиска: Расположено над таблицей. Позволяет фильтровать данные в реальном времени.
  • Таблица данных (Grid): Центральная часть экрана, где отображаются списки (студентов, коробок, документов и т.д.).
  • Строка состояния (внизу): Слева показывает количество строк или статус операции, справа — текущие дату и время.

2. Навигация и просмотр данных

Для просмотра конкретной категории архивных данных используйте главное меню.

Раздел "Данные"

  • Пользователи: Доступно только администратору. Просмотр списка сотрудников системы.
  • Группы: Список учебных групп (специальность, год создания).
  • Коробки: Реестр архивных коробок с указанием стеллажа, полки и типа хранимых документов.

Раздел "Студенты"

  • Студенты: Основной список обучающихся.
  • Персональные файлы: Сведения о личных делах (год поступления, отчисления, причина).
  • Удаленные перс. файлы: Архив отчисленных студентов или закрытых дел.
  • Документы работ: Список курсовых/дипломных работ, привязанных к студентам.
  • Удаленные док. работ: Список удаленных записей о работах.

Раздел "Справочник"

  • Типы документов: Настройка классификатора типов документов.
Примечание: При переключении раздела таблица автоматически обновляется. Если таблица пуста, кнопки действий будут недоступны.

3. Поиск и фильтрация

Система поддерживает быстрый поиск по всем видимым полям текущей таблицы.

Рис. 2. Поле поиска

  1. Выберите нужный раздел (например, Студенты).
  2. Начните вводить текст в поле "Search" над таблицей.
  3. Таблица мгновенно отфильтрует строки, оставляя только те, которые содержат введенный текст.

Чтобы сбросить фильтр, просто очистите поле поиска.

4. Редактирование данных (CRUD)

Управление записями можно осуществлять тремя способами:

  • Через кнопки под таблицей (Добавить, Редактировать, Удалить).
  • Через контекстное меню (правая кнопка мыши по таблице).
  • Через панель инструментов сверху.

Рис. 3. Контекстное меню таблицы

Добавление новой записи

  1. Нажмите кнопку Добавить (или пункт меню "Добавить").
  2. Откроется форма ввода (зависит от выбранной таблицы).
  3. Заполните обязательные поля. Для выбора связанных данных (например, Группа или Студент) используйте выпадающие списки.
  4. Нажмите OK для сохранения или Отмена.

Редактирование

  1. Выделите одну строку в таблице.
  2. Нажмите Редактировать.
  3. Внесите изменения в открывшейся форме и сохраните их.

Удаление

  1. Выделите одну или несколько строк (зажав Ctrl или Shift).
  2. Нажмите Удалить.
  3. Подтвердите действие во всплывающем окне.
Внимание! Удаление записей из основных таблиц (например, "Студенты") может повлечь удаление связанных данных в других таблицах.

5. Печать и формирование отчетов

Меню "Печати" позволяет генерировать документы Word (.docx) на основе выбранных данных.

Личное дело студента

Формирует обложку личного дела с данными о сроках обучения и количестве листов.

  1. Перейдите в раздел Студенты > Студенты или Персональные файлы.
  2. Выделите нужного студента.
  3. Выберите в меню: Печати -> Получить данные по выбранному студенту.
  4. Укажите путь для сохранения файла.

Опись дипломных работ

Создает таблицу с темами ВКР для всей группы.

  1. Перейдите в раздел Данные > Группы (или выберите студента из нужной группы).
  2. Выберите группу.
  3. Выберите в меню: Печати -> Получить опись по дипломным работам выбранной группы.

Файл навигации по архиву

Позволяет собрать сложный отчет, включающий информацию о разных группах, студентах и документах в одном файле.

  1. Выберите объект в таблице (Группу, Студента или Документ).
  2. В меню выберите Печати -> Составление файла(docx) навигации по архиву.
  3. Нажмите Добавить... (выберите соответствующий пункт: добавить документ, студента или группу).
  4. Повторите для всех нужных объектов.
  5. Нажмите Сгенерировать для создания итогового файла.
  6. Используйте Очистить документ, чтобы начать сборку заново.

Рис. 4. Меню формирования печатных форм

6. Роли пользователей

Роль Права доступа
Администратор Полный доступ. Видит пункт меню "Пользователи", может управлять учетными записями.
Менеджер / Сотрудник Доступ к данным архива, добавление/редактирование записей, печать отчетов. Пункт "Пользователи" скрыт.

7. Контекстная фильтрация данных

Для более точного поиска записей в таблице используется система контекстных фильтров. Она позволяет отображать только те строки, которые содержат конкретные значения в определенных колонках.

Рис. 5. Меню контекстной фильтрации

Как открыть фильтр

  1. Нажмите правую кнопку мыши в любом месте таблицы с данными.
  2. В появившемся меню выберите пункт "Фильтр".
  3. Откроется подменю со списком доступных колонок (например, "Группа", "Тип", "Студент").

Использование фильтров

  • Фильтрация по значению: Наведите курсор на нужную колонку (например, "Группа") и выберите конкретное значение из списка (например, "ИС-21"). В таблице останутся только студенты этой группы.
  • Сброс фильтра колонки: Чтобы снять фильтр с конкретной колонки, снова откройте меню этой колонки и выберите пункт "Все".
  • Множественная фильтрация: Вы можете одновременно фильтровать данные по нескольким колонкам. Например, выбрать группу "ИС-21" и тип документа "Диплом". Строки должны соответствовать всем выбранны условиям.

Визуальная индикация

Система подсвечивает активные фильтры для удобства:

  • Если для колонки установлен фильтр, её название в меню подсвечивается светло-зеленым цветом.
  • Конкретное выбранное значение в списке также выделяется зеленым.
  • Пункт "Сбросить все фильтры" в корне меню становится активным (и также может подсвечиваться), если хотя бы один фильтр применен.
Обратите внимание: В меню отображаются только те колонки, которые имеют различные значения (более одного уникального значения) и меньше строк, чем всего в таблице. Это оптимизирует работу меню.
