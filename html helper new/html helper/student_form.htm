Справка по форме добавления/редактирования студента

Общее описание

Форма StudentForm предназначена для добавления или изменения данных о студенте и его личном деле в архивном фонде. В зависимости от переданных параметров форма может работать в режиме добавления нового студента или редактирования существующего.

Элементы формы и их назначение

1. Поле «ФИО студента»

Предназначено для ввода полного имени студента.

  • Максимальная длина: 100 символов.
  • Пример заполнения: Иванов Иван Иванович.
  • Поле обязательное для заполнения (отмечено звёздочкой *).

2. Выпадающий список «Группа»

Позволяет выбрать группу, к которой относится студент.

  • Список заполняется автоматически из базы данных.
  • Можно начать вводить текст для поиска нужной группы.

3. Поле «Год поступления»

Позволяет выбрать год поступления студента с помощью календаря.

  • Можно использовать кнопки вверх/вниз для изменения года.
  • Поле обязательное для заполнения (отмечено звёздочкой *).

4. Поле «Год вычета»

Позволяет указать год вычета студента.

  • По умолчанию поле отключено.
  • Активируется, если снят флажок «Не сохранять».

5. Поле «Причина вычета»

Многострочное поле для указания причины вычета студента.

  • Максимальная длина: 100 символов.
  • Пример заполнения: Завершил обучение или Отчислен по причине….

6. Флажок «Студента в удалённые?»

Указывает, следует ли переместить студента в категорию удалённых записей.

  • Если флажок установлен, студент будет помечен как удалённый.

Процесс работы с формой

  1. Откройте форму StudentForm.
  2. Введите ФИО студента в поле «ФИО студента».
  3. Выберите группу из выпадающего списка «Группа».
  4. Укажите год поступления в поле «Год поступления».
  5. При необходимости установите флажок «Студента в удалённые?».
  6. Если нужно указать год вычета:
    • Снимите флажок «Не сохранять».
    • Выберите год вычета в соответствующем поле.
    • При необходимости укажите причину вычета в многострочном поле.
  7. Нажмите кнопку «Сохранить» для сохранения данных или «Отмена» для выхода без сохранения.
  8. При сохранении система проверит заполнение обязательного поля «ФИО студента» и выдаст сообщение об ошибке, если поле не заполнено.

Важные замечания

  • Все обязательные поля отмечены звёздочкой (*).
  • Если вы редактируете существующего студента, поля формы будут предварительно заполнены данными из базы.
  • При сохранении данных система автоматически проверяет корректность заполнения обязательных полей.

    • Особые случаи и подсказки

    • Если студент завершает обучение:
      • Укажите год вычета.
      • В поле «Причина вычета» можно указать «Завершил обучение».
    • Если студент отчислен:
      • Обязательно укажите год вычета.
      • Подробно опишите причину отчисления в соответствующем поле.
    • Для архивных записей:
      • Установите флажок «Студента в удалённые?», если студент больше не числится в учебном заведении.
      • Используйте флажок «Не сохранять», если информация о годе вычета неактуальна или недоступна.

    Возможные ошибки и их устранение

    Ошибка Причина Способ устранения
    «Не введено ФИО студента!» Поле «ФИО студента» оставлено пустым. Введите полное ФИО студента в соответствующее поле.
    Не сохраняется год вычета Установлен флажок «Не сохранять». Снимите флажок «Не сохранять» и выберите год вычета.
    Нет доступных групп в списке База данных групп не загружена. Проверьте подключение к базе данных и обновите список групп.

    Рекомендации по использованию

    1. Перед добавлением нового студента убедитесь, что группа, к которой он относится, существует в системе.
    2. При редактировании данных всегда проверяйте актуальность информации.
    3. Для архивных записей используйте флажок «Студента в удалённые?» для корректного учёта.
    4. Если информация о годе вычета недоступна или неактуальна, используйте флажок «Не сохранять».
    5. После сохранения данных проверьте, что информация корректно отобразилась в основной базе данных.
