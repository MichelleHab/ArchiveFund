# Модули приложения ArchiveFund

## 1. Точка входа и инициализация
Отвечает за запуск приложения, чтение конфигурации, проверку структуры базы данных, создание пользователя по умолчанию, выполнение резервного копирования и определение начального сценария (авторизация или прямой вход в режиме отладки).

## 2. Работа с базой данных
Центральный модуль для всех операций с СУБД. Управляет подключением, выполняет запросы на выборку, скалярные значения и модификацию данных. Реализует функции экспорта и импорта базы данных, а также обработку исключений при работе с данными.

## 3. Авторизация пользователей
Обеспечивает вход в систему: проверка учётных данных, хэширование паролей, определение роли пользователя и передача контекста безопасности в главный интерфейс. Включает визуальные компоненты формы входа.

## 4. Главный интерфейс управления
Основное окно приложения после авторизации. Отображает данные из всех таблиц системы с учётом ролевой модели. Поддерживает динамическое формирование запросов с объединениями таблиц, поиск, преобразование периодов, маскирование конфиденциальных данных, экспорт отчётов в формат Word и печать.

## 5. Контекстная фильтрация данных
Реализует интерактивное меню для фильтрации отображаемых данных по колонкам. Обеспечивает подсветку соответствующих записей, поддержку множественных условий, сброс фильтров и сохранение контекста выбранной ячейки.

## 6. Генерация структурированных отчётов
Модуль формирования документов в формате DOCX. Создаёт описания архивных единиц, генерирует отчёты по студентам и учебным группам, поддерживает включение информации об удалённых записях.

## 7. Формы управления справочниками и сущностями

### Управление местами хранения
Интерфейс для создания и редактирования записей о физических контейнерах. Позволяет указывать тип, принадлежность к группе, местоположение (стеллаж, полка) и год размещения.

### Управление документами
Форма для работы с архивными документами. Обеспечивает связь с типами документов, студентами и местами хранения. Поддерживает процедуру архивации и восстановления записей.

### Управление типами документов
Справочник классификаторов документов. Включает валидацию вводимых данных при создании и изменении записей.

### Управление учебными группами
Редактирование информации об учебных группах: год набора, специализация, наименование.

### Управление студентами
Работа с персональными данными студентов, ведение личных дел, фиксация факта отчисления, привязка к годам обучения.

### Управление учётными записями
Административный интерфейс для управления пользователями системы: назначение ролей, изменение логина и пароля, редактирование ФИО сотрудников.

## 8. Ресурсы приложения
Хранит строковые константы, тексты интерфейса и ресурсы для локализации приложения.

---

## Внешние зависимости

- **MySQL Connector/NET** — драйвер для подключения к СУБД MySQL
- **MySqlBackup.NET** — библиотека для выполнения резервного копирования и восстановления базы данных
- **DocX** — библиотека для создания и редактирования документов Microsoft Word (.docx) без установки Office

## Структура базы данных

Система использует следующие таблицы:
- Места хранения (контейнеры)
- Документы (актуальные и удалённые)
- Классификатор типов документов
- Студенты и их личные дела (актуальные и удалённые)
- Учебные группы
- Пользователи системы
