4.2.2. Ошибка при сохранении данных

Ошибка при сохранении данных возникает при попытке добавить, изменить или удалить запись. Программа показывает следующее сообщение:

Конкретные примеры ошибок

Рис. 2. Пример ошибки дублирования имени коробки

Пример: дублирование имени коробки

В таблице «Коробки» поле «box_name» должно быть уникальным. Если вы попытаетесь создать коробку с уже существующим именем, появится ошибка.

Решение: используйте уникальное имя или отредактируйте существующую коробку.

Рис. 3. Ошибка внешнего ключа при выборе несуществующего типа документа

Пример: несуществующий тип документа

Если в выпадающем списке выбран тип документа, который был удалён из справочника после открытия формы, при сохранении возникнет ошибка.

Решение: обновите форму (закройте и откройте заново) или выберите существующий тип из списка.


Что делать при повторяющихся ошибках

1. Проверьте соединение с базой данных — возможно, проблема временная.

2. Проверьте журнал ошибок MySQL — может содержать дополнительную информацию.

3. Создайте резервную копию и попробуйте выполнить операцию снова.

4. Обратитесь к администратору — возможно, требуются права на изменение структуры базы данных.

Причина Решение
Нарушение уникальности (дубликат) Проверьте, что имя коробки, логин пользователя или название группы не повторяются. Эти поля должны быть уникальными
Обязательные поля не заполнены Убедитесь, что все поля, отмеченные звёздочкой (*), заполнены (ФИО студента, тема документа, тип документа и т.д.)
Нарушение внешнего ключа Проверьте, что выбранные значения из выпадающих списков существуют в справочниках (например, выбранный тип документа должен существовать в справочнике «Типы документов»)
Неверный формат данных Проверьте, что в числовых полях введены числа, а даты выбраны корректно
Превышение длины поля Уменьшите длину вводимого текста (например, ФИО не более 100 символов, тема документа не более 100 символов)
Отсутствие прав на запись Убедитесь, что пользователь MySQL имеет права INSERT, UPDATE, DELETE на таблицы базы данных
Сервер MySQL недоступен Проверьте подключение к серверу (раздел 4.2.1)
