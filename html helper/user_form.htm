Справка по форме управления пользователями (UserForm)

Общее описание

Форма UserForm предназначена для добавления и редактирования учётных записей пользователей системы архивного фонда. В зависимости от переданных параметров форма может работать в режиме добавления нового пользователя или редактирования существующего.

Элементы формы и их назначение

1. Поле «ФИО» (txtFIO)

Предназначено для ввода полного имени пользователя.

  • Максимальная длина: 150 символов.
  • Пример заполнения: Иванов Иван Иванович.

2. Выпадающий список «Роль» (cmbRole)

Позволяет выбрать роль пользователя в системе.

  • Доступные варианты: Admin, Employer.
  • Выбор обязателен для заполнения (отмечено звёздочкой *).
  • Список нельзя редактировать — только выбирать из предложенных вариантов.

3. Поле «Логин» (txtLogin)

Предназначено для ввода логина пользователя для входа в систему.

  • Максимальная длина: 50 символов.
  • Пример заполнения: Ivanov_II.
  • Поле обязательное для заполнения (отмечено звёздочкой *).

4. Поле «Пароль» (txtPassword)

Предназначено для ввода пароля пользователя.

  • Максимальная длина: 50 символов.
  • При добавлении нового пользователя поле обязательно для заполнения.
  • При редактировании существующего пользователя ввод пароля не обязателен.

7. Кнопка «Создать резервную копию» (btnBackup)

Позволяет создать резервную копию базы данных пользователей.

  • Открывает диалог выбора места сохранения файла.
  • Файл сохраняется в формате .sql с автоматически сгенерированным именем.
  • Перед созданием копии запрашивается подтверждение.

8. Кнопка «Восстановить резервную копию» (btnRestore)

Позволяет восстановить базу данных из ранее созданной резервной копии.

  • Открывает диалог выбора файла резервной копии (.sql).
  • Перед восстановлением выводится предупреждение о возможной перезаписи текущих данных.
  • После успешного восстановления выводится сообщение об успехе.

Возможные ошибки и их устранение

Ошибка Причина Способ устранения
«Не выбрана роль!» Поле «Роль» оставлено пустым. Выберите роль из выпадающего списка.
«Не введён логин!» Поле «Логин»оставлено пустым. Введите логин в соответствующее поле.
«Не введён пароль!» При добавлении нового пользователя поле «Пароль» оставлено пустым. Введите пароль в соответствующее поле.
Ошибка при создании резервной копии Недостаточно прав для записи файла или ошибка в процессе экспорта базы данных. Проверьте права доступа к выбранной папке и убедитесь, что база данных доступна.
Ошибка при восстановлении резервной копии Выбран некорректный файл или ошибка в SQL-скрипте. Убедитесь, что выбран файл резервной копии (.sql), созданный этой же системой.

Рекомендации по безопасности

  • При выборе роли:
    • Admin — предоставляет полный доступ к системе, включая управление пользователями и резервными копиями.
    • Employer — ограниченный доступ, без прав на администрирование и работу с резервными копиями.
  • При создании пароля: используйте комбинацию букв, цифр и специальных символов, минимум 8 символов.
  • Резервные копии: регулярно создавайте резервные копии базы данных и храните их в безопасном месте.
  • Восстановление из резервной копии: перед восстановлением убедитесь, что вы понимаете последствия — текущие данные могут быть перезаписаны.

Пошаговая инструкция по работе с резервными копиями

Создание резервной копии

  1. Нажмите кнопку «Создать резервную копию».
  2. В открывшемся диалоге выберите папку для сохранения и подтвердите имя файла (по умолчанию: backup_ГГГГММДД_ЧЧММСС.sql).
  3. Подтвердите создание копии в появившемся окне.
  4. Дождитесь сообщения об успешном создании копии.

Восстановление из резервной копии

  1. Нажмите кнопку «Восстановить резервную копию».
  2. Выберите файл резервной копии (.sql) в открывшемся диалоге.
  3. Внимательно прочитайте предупреждение о возможной перезаписи текущих данных.
  4. Подтвердите восстановление.
  5. Дождитесь сообщения об успешном восстановлении.

Особые случаи

  • Редактирование пользователя: при открытии формы в режиме редактирования поле пароля остаётся пустым для безопасности. Если нужно изменить пароль, введите новый.
  • Отсутствие данных: если форма открывается без параметров, все поля остаются пустыми для ввода новых данных.
