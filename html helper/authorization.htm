Авторизация в системе

При запуске приложения открывается окно авторизации. Для входа в систему необходимо ввести логин и пароль.

Шаг 1: Окно авторизации

Окно авторизации имеет размер 554x187 пикселей и содержит два поля ввода и кнопку входа.

[Скриншот окна авторизации]
Рис. 1. Окно авторизации

Шаг 2: Ввод логина

  1. Введите ваш логин в поле "Логин" в верхней части окна.
  2. Логин должен быть введен точно, как он был зарегистрирован в системе.
  3. Пример формата логина: Ivanov_II.
  4. Поле логина является обязательным для заполнения.
[Скриншот поля ввода логина]
Рис. 2. Поле ввода логина

Шаг 3: Ввод пароля

  1. Введите ваш пароль в поле "Пароль" в нижней части окна.
  2. Пароль отображается скрытыми символами (звёздочками или точками) для безопасности.
  3. Убедитесь, что раскладка клавиатуры соответствует той, которая использовалась при установке пароля.
[Скриншот поля ввода пароля]
Рис. 3. Поле ввода пароля (символы скрыты)

Шаг 4: Вход в систему

  1. После ввода логина и пароля нажмите кнопку "Войти", расположенную справа от полей ввода.
  2. Система выполнит проверку введённых данных сверкой с базой данных.
  3. При успешной авторизации откроется главное окно программы.
[Скриншот кнопки входа]
Рис. 4. Кнопка входа

Сообщения об ошибках

  • "Не введен логин!" — Поле логина пустое. Пожалуйста, введите ваш логин.
  • "Не введен пароль!" — Поле пароля пустое. Пожалуйста, введите ваш пароль.
  • "Данный логин не найден!" — Пользователь с таким логином не существует в базе данных.
  • "Неверный логин или пароль!" — Пароль не совпадает с сохранённым в базе данных.

Успешная авторизация

После успешного входа в систему:

  1. Окно авторизации закроется.
  2. Откроется главное окно программы ArchiveFund.
  3. В заголовке главного окна будут отображены ваш логин и ФИО.
[Скриншот главного окна после авторизации]
Рис. 5. Главное окно программы
Примечание: Пароли хранятся в базе данных в хешированном виде с использованием алгоритма SHA-512, что обеспечивает высокий уровень безопасности.
Внимание! Если вы забыли свой пароль, обратитесь к администратору системы для его сброса.
