Справка по форме добавление/редактирование группы

Общее описание

Форма GroupForm используется для добавления или изменения информации о группе архивного фонда. В зависимости от переданных параметров форма может работать в режиме добавления новой группы или редактирования существующей.

Элементы формы и их назначение

1. Поле «Название группы» (txtGroupName)

Предназначено для ввода названия группы архивного фонда.

  • Максимальная длина: 100 символов.
  • Пример заполнения: Гр-1а.
  • Поле обязательное для заполнения (отмечено звёздочкой *).

2. Поле «Год формирования» (dtpFormationYear)

Позволяет выбрать год формирования группы с помощью календаря.

  • Формат отображения: только год (yyyy).
  • Можно использовать кнопки вверх/вниз для изменения года.
  • Поле обязательное для заполнения (отмечено звёздочкой *).

3. Поле «Специализация» (cmbSpecialization)

Выпадающий список для выбора специализации группы.

  • Список заполняется автоматически из базы данных.
  • Можно начать вводить текст для поиска нужного значения.
  • Поле обязательное для заполнения (отмечено звёздочкой *).

Процесс работы с формой

  1. Откройте форму GroupForm.
  2. Введите название группы в поле «Название группы».
  3. Выберите год формирования с помощью календаря в поле «Год формирования».
  4. Выберите или введите специализацию в выпадающем списке «Специализация».
  5. Нажмите кнопку «Принять» для сохранения данных или «Отмена» для выхода без сохранения.
  6. При сохранении система проверит заполнение обязательных полей и выдаст сообщение об ошибке, если какое-то поле не заполнено.

Важные замечания

  • Все обязательные поля отмечены звёздочкой (*).
  • Если вы редактируете существующую группу, поля формы будут предварительно заполнены данными из базы.
  • После успешного сохранения форма закрывается и возвращает результат DialogResult.OK.
  • При нажатии «Отмена» форма закрывается без сохранения и возвращает DialogResult.Cancel.
