Редактирование и добавление документов

Форма DocumentForm предназначена для ввода мета-данных архивного документа: темы, авторов, типа и местоположения. Поля, отмеченные звездочкой, являются обязательными для заполнения.

Рис. 1. Общий вид формы редактирования документа

1. Основная информация

Верхняя часть формы содержит ключевые сведения о содержании документа.

* Тема документа Многострочное текстовое поле
Введите краткое описание или заголовок работы (например: «Анализ современного обучения»).
Удаленный документ? Чекбокс.
Устанавливается, если документ помечен как удаленный (архивная пометка).

2. Классификация и дата

Параметры, определяющие тип документа и время его создания.

Рис. 2. Выбор типа и года создания
  • * Год создания: Выберите год в календаре.
  • * Тип документа: Выберите из выпадающего списка. Список формируется из справочника типов.

3. Авторы и хранение

Нижняя часть формы связывает документ с конкретными людьми и физическим носителем.

ФИО руководителя Выпадающий список.
Выберите научного руководителя или ответственное лицо.
* Студент Выпадающий список.
Обязательное поле. Выберите студента-автора работы из базы данных.
Коробка хранения Выпадающий список.
Указывает физическое расположение документа. Формат отображения: id:ID_коробки -> Имя_коробки.

4. Сохранение изменений

После заполнения полей используйте кнопки в нижней части окна:

  • Принять — попытка сохранить данные. Перед сохранением система выполняет проверку:
Проверка целостности данных:
Если не заполнено одно из обязательных полей, сохранение будет отменено, и появится одно из сообщений:
  • «Не введена тема документа!»
  • «Не выбран тип документа!»
  • «Не выбран студент!»
  • Отмена — закрыть форму без сохранения внесенных изменений.
