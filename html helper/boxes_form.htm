Справочная система: форма BoxesForm (Архивный фонд)

Общее описание

Форма BoxesForm предназначена для добавления или изменения данных о коробках в архивном фонде. В зависимости от переданных параметров форма открывается в режиме добавления (Добавление коробки) или редактирования (Изменение коробки).

Инструкция по заполнению

1. Номер стеллажа

Укажите номер стеллажа, на котором находится коробка.

  • Поле: Номер стеллажа
  • Элемент: NumericUpDown (numericRackNumber)
  • Допустимые значения: целые числа

2. Номер полки

Введите номер полки на выбранном стеллаже.

  • Поле: Номер полки
  • Элемент: NumericUpDown (numericShelfNumber)
  • Допустимые значения: целые числа

3. Имя коробки

При необходимости укажите имя коробки. Если поле пустое и заполнены номера стеллажа и полки, автоматически подставится значение вида Box:X-Y.

  • Поле: Имя
  • Элемент: TextBox (txtName)
  • Подсказка: Box:1-1

4. Целевая группа

Выберите целевую группу из выпадающего списка.

  • Поле: Целевая группа
  • Элемент: ComboBox (cmbGroupId)
  • Данные загружаются из таблицы Group

5. Целевой тип

Обязательное поле. Выберите целевой тип из выпадающего списка. Без выбора типа сохранить данные нельзя.

  • Поле: *Целевой тип
  • Элемент: ComboBox (cmbTypeId)
  • Данные загружаются из таблицы DocumentTypes

6. Год работы

Укажите год работы. По умолчанию поле отключено; чтобы активировать, снимите галочку «Не сохранять».

  • Поле: Год работы
  • Элемент: DateTimePicker (dtpYearWork)
  • Формат: yyyy

7. Опция сохранения даты

Если отмечена галочка «Не сохранять», поле «Год работы» будет неактивно, и дата не сохранится.

  • Элемент: CheckBox (noSaveDate)
  • По умолчанию: отмечено

Действия

Сохранить

Нажатие кнопки Принять проверяет заполнение обязательного поля «Целевой тип». Если тип не выбран, выводится сообщение об ошибке. В противном случае форма возвращает DialogResult.OK.

  • Кнопка: Принять
  • Элемент: Button (btnSave)
  • Обработчик: BtnSave_Click

Отмена

Нажатие кнопки Отмена закрывает форму без сохранения данных.

  • Кнопка: Отмена
  • Элемент: Button (btnCancel)
  • Обработчик: BtnCancel_Click

Особые случаи

  • При открытии формы в режиме Изменение коробки поля заполняются переданными параметрами.
  • Если поле Имя пустое и номера стеллажа/полки заданы, имя автоматически генерируется как Box:Rack-Shelf.
  • Обязательное поле Целевой тип блокирует сохранение, пока не будет выбран вариант.
