Работа с формой «Коробки»

Данная форма используется для регистрации новых архивных коробок или редактирования сведений о существующих. Ниже приведено описание элементов интерфейса и порядка действий.

Обратите внимание: Заголовок окна автоматически меняется на «Изменение коробки!», если вы открыли существующую запись. В противном случае отображается «Добавление коробки!».

1. Физическое расположение

В верхней части формы указывается место хранения коробки.

Рис. 1. Блок указания местоположения
  • Номер стеллажа — введите номер стеллажа (числовое поле).
  • Номер полки — введите номер полки.
  • Имя — уникальное имя коробки.
    Совет: Если нажать на это поле после ввода стеллажа и полки, система автоматически предложит имя в формате Box:Стеллаж-Полка (например, Box:1-1). Вы можете отредактировать его вручную.

2. Классификация и дата

Центральная часть формы отвечает за типологию содержимого.

Рис. 2. Параметры классификации
Элемент Описание действия
Целевая группа Выберите группу из выпадающего списка. Список загружается из справочника групп.
*Целевой тип Обязательное поле. Выберите тип документа. Без выбора типа сохранение невозможно.
Год работы Поле выбора года. Активно только если снята галочка «Не сохранять».
Не сохранять Чекбокс. Если он установлен (по умолчанию), поле «Год работы» заблокировано. Снимите галочку, чтобы указать год.

3. Завершение работы

В нижней части формы расположены кнопки управления.

Рис. 3. Кнопки управления
  • Принять — сохраняет изменения.
    Если поле *Целевой тип не заполнено, система выдаст предупреждение: «Не введен тип! Пожалуйста выберите из предложенных.»
  • Отмена — закрывает форму без сохранения данных.
