Документация проекта ArchiveFund
=================================

Описание проекта: Система управления архивным фондом документов студентов и учебных групп на основе Windows Forms и MySQL.

================================================================================
1. ТОЧКА ВХОДА ПРИЛОЖЕНИЯ (Program.cs)
================================================================================

Класс: Program
--------------
Основной класс приложения, содержащий точку входа и методы инициализации.

Метод: Main()
-------------
Статический метод [STAThread], являющийся точкой входа в приложение.
Функциональность:
- Устанавливает таймаут подключения к базе данных (1 секунда)
- Проверяет наличие файла конфигурации config.ini
- При наличии config.ini:
  * Парсит параметры подключения (server, port, database, user, password)
  * Проверяет существование указанной базы данных
  * Если база данных не найдена - загружает пустую версию из ArchiveFund.06.clear.sql
  * Проверяет соответствие табличной структуры
  * При несоответствии структуры создаёт резервную копию и пересоздаёт базу
  * Создаёт пользователя MySQL с указанными правами доступа если он не существует
  * Применяет настройки подключения из конфигурации
- При отсутствии config.ini или ошибке:
  * Использует настройки по умолчанию (localhost, база ArchiveFund)
- Запускает форму авторизации (Authorization) в релизном режиме
- В отладочном режиме сразу открывает MainForm с правами администратора

Метод: IsValidServerAddress(string server)
------------------------------------------
Статический метод проверки корректности IP-адреса сервера.
Параметры: server - строка с адресом сервера
Возвращаемое значение: bool (true если адрес корректен)
Проверки: localhost, %, 127.0.0.1, валидация IPv4-адреса

Класс: Sql - Внутренний класс для выполнения SQL-запросов к базе данных MySQL.

Свойство: ConnectionStringBuilding - MySqlConnectionStringBuilder с настройками по умолчанию

Методы:
- Query(request, parameters) - выполнение SELECT-запросов с возвратом DataTable
- QueryOneReturn(request, parameters) - выполнение запроса с возвратом одного значения
- QueryNonReturns(request, parameters) - выполнение INSERT/UPDATE/DELETE, возвращает bool
- ExportToFile(filePath, database) - экспорт базы данных в SQL-файл
- ImportFromFile(filePath) - импорт базы данных из SQL-файла
- SqlRequestErrors(ex) - обработка ошибок SQL-запросов

АРХИТЕКТУРНЫЕ ПРИМЕЧАНИЯ
================================================================================

Паттерны: Repository Pattern (Sql), MVC-like разделение, Dependency Injection
Безопасность: Параметризированные запросы, хэширование SHA2-512, роли
Обработка ошибок: Try-catch, диалоговые сообщения, DEBUG режим
CRUD операции: Через диалоговые формы
Фильтрация: Контекстная в DataGridView
Отчётность: Генерация Word через Xceed.Words.NET
